# Tarea 3 – Cómputo en la nube

Despliegue en AWS de una aplicación web en contenedores conectada a una base de datos MySQL. La infraestructura está en [`IAC/`](IAC/README.md), definida con Terraform, y la aplicación en [`APP/`](APP/README.md), con un pipeline de GitHub Actions que construye su imagen y la publica en Amazon ECR.
